- 相手NPCの画像、候補追加時の自動生成、イベント挿絵、デート場面、表情差分は**今回の範囲外（未制作）**。

## 共通の撮影条件と描き分けの方針

`scripts/gemini/portraitSpecs.ts` に、生成前の記録として20人分の顔立ち・髪型・服装・年齢・容姿レベル・避けることを保存しています。

- 架空の日本人成人1人、実写風、柔らかい昼の自然光、明るいグレーベージュの無地背景、目線の高さ・正面に近い胸上、普通に清潔な無地の私服、口を閉じた穏やかな表情、縦4:5、1K。
- 職業を示す服装（白衣・スーツ・制服）、文字・数値・透かしは描かない。
- 容姿1・2は「顔立ちの構成」で描き分け、照明・服装の質・不潔さ・表情・加齢・肌色・障害を代理にしない。低レベルの人物同士で特徴の組み合わせを変える（M07：目元控えめ・頬の量感・丸い鼻先・小さめの顎／M08：面長・広い額・下がり目・低く広い鼻・後退気味の顎／F06：面長・小さめの目元・鼻と口元の存在感・口元から顎の不均衡／F08：エラの張った四角い輪郭・離れた目・丸く大きめの鼻・薄い唇と左右差のある太い眉 など）。
